# Code Quality & Standards Index

> **Overview:** Central navigation index and enforcement guide for the Agentic Dev, establishing strict development hygiene, testing mandates, type discipline, and component reusability patterns.  
> **When to Use:** Consult before writing, refactoring, or verifying any application code or UI components.

---

## 1. Navigational Routing Matrix

| Development Focus | Reference Document | Core Mandate |
| :--- | :--- | :--- |
| Writing Logic, Routes, or Transforms | `CODE_QUALITY.md` | Strict types, zero `any`, runtime Zod validation, pure helpers |
| Building or Refactoring UI Elements | `COMPONENT_REUSABILITY.md` | Pre-implementation inventory, Rule of Two, clean composable props |
| Testing & Static Analysis | `CODE_QUALITY.md` | Mocked boundaries, Vitest unit tests, clean lint reports |
